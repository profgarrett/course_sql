# Problem: What is Morgantown's weather?

We will use concepts from [SQL 2](./sql02-select) to investigate Morgantown's weather patterns.
## Outcome

- Practice `SELECT`, `FROM`, `WHERE`, `ORDER BY`, `AS`, and other concepts introduced in SQL2.
## Process
- Download the [db file](/course_sql/sql02-morgantowndocks/ghcn_daily_morgantowndocks.db)  
- Download the [sql file](course_sql/sql02-morgantowndocks/problem.sql) 
- Move both files into a new folder.
- Open *DB Browser* and choose *File* / *Open DB*
- Go to the execute SQL tab. Then, use the 2nd button from the left to open the SQL file
- Start answering questions!
